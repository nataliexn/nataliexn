### 🃏 HighLo — Blackjack Card Counting Assistant 🚧 *In Progress*
`JavaScript` · `React` · `Vite` · `Vercel` · [🔗 View on GitHub](https://github.com/nataliexn/HighLo) · [🌐 Live Demo](https://highlo.vercel.app)

A web dashboard for HighLo, a blackjack table-assist system built around the Hi-Lo card counting strategy.
- **UI-first React app** built with Vite and deployed on Vercel
- Dashboard screens designed to display the state of a hand in progress
- Computer-vision input is currently **mocked** with realistic sample data, so the interface can be developed and tested ahead of the detection layer
